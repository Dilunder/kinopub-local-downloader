KinoPub Local Downloader — Windows x64

1. Скачайте KinoPub-Local-Downloader.exe из Assets в GitHub Releases.
2. Запустите двойным щелчком. Установка Python, pip и ffmpeg не требуется.
3. Дождитесь распаковки при первом запуске. Откроется окно управления
   и ваш обычный браузер с локальным интерфейсом.
4. В настройках выберите папку загрузок и свои cookies/браузер.
5. Для завершения нажмите «Остановить и закрыть» в окне управления.

Интерфейс работает только на 127.0.0.1. По умолчанию порт 8000;
если он занят, выбирается свободный порт 8001–8010.
При повторном запуске открывается уже работающий экземпляр.

Настройки, cookies и история: %LOCALAPPDATA%\KinoPubLocalDownloader\data
Видео по умолчанию: %USERPROFILE%\Downloads\KinoPub
При обновлении замените EXE, папка данных сохраняется.
Данные исходного Python-проекта не переносятся автоматически.

Python, yt-dlp, плагин, ffmpeg и ffprobe включены в файл. Из-за
ffmpeg файл большой; запуск требует времени и свободного места во
временной папке Windows. При скачивании видео нужен доступ к сайту.

Файл не подписан коммерческим сертификатом. Проверяйте источник
загрузки и SHA256SUMS.txt; защиту Windows отключать не нужно.

Исходники и материалы сторонних компонентов находятся в репозитории
проекта и приложенных материалах релиза (third-party-notices.zip).
Используйте собственный аккаунт и только разрешённые вам материалы.
